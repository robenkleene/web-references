# Google Docs Markdown

- `Tools > Preferences > Enable Markdown`: Enable Markdown support
- `Edit > Paste from Markdown`

## Inline Code

There's no built in way to apply inline code (but doing a backtick will switch to an inline code style).

To work around this, use the `Paint Format` tool, but selecting some inline code style text, then clicking the `Paint Format` tool, then selecting the text where the style should be applied (it will immediately be applied when the selection is applied.
